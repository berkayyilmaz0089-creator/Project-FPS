# Project FPS

Welcome to Project FPS. This is a base game or a core framework that aims to let developers and/or game development enthusiasts make their own 3D FPS style games in Unity (I know that other engines could do this and Unity is in a weird situation but I am just used to working in this and I still tbink it is a great engine that can do every kind of game that I could want. At least the licensing is better now, you know?). While this project is optimized for FPS games in general, it can also be partially or completely used for other genres and games. This project includes:

1. Player Movement and Look scripts that let the player move and look around, jump, crouch, and sprint without any physics bugs
2. Player Audio like footsteps depending on the speed and surface tag, jump and land sounds
3. Save/Load system which handles saveable objects and scripts through ISaveable

This project includes third-party digital assets (including 3D models, textures, sound effects, and animations) obtained from open platforms under their respective free and attribution-friendly licensing terms. These assets are integrated solely for demonstration, testing, and aesthetic representation. They do not constitute the core functionality or original codebase of the framework. A credit list is formally documented in the LICENSINGINFO.md file included in this repository.

No generative AI was used when developing this project. (No asset, scene or configuration was and will not be made by generative AI.
